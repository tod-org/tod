Add `update_project`, `archive_project`, and `unarchive_project` API functions to the Todoist client, plus corresponding CLI subcommands (`tod project update`, `tod project archive`, `tod project unarchive`). The update function sends a POST to `/projects/{id}` with optional fields (name, color, is_favorite, view_style). Archive and unarchive send POST to `/projects/{id}/archive` and `/projects/{id}/unarchive`, both returning 204 with no body. Also consider exposing `GET /projects/archived` for listing archived projects.
